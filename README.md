# 테트리스 노트

위키형 정적 웹페이지입니다.

## 구성

- `index.html`: 메인 문서
- `css/style.css`: 전체 스타일
- `js/script.js`: 검색, 메뉴, 다크모드, 읽기 진행률
- `images/`: 문서에 쓰는 이미지

## v3 수정 사항

- 카드 그림자 제거
- 둥근 모서리 제거
- 과한 그라데이션과 장식 최소화
- 문서형 위키에 가까운 평평한 레이아웃으로 조정
- 기존 이미지 유지

이미지를 추가로 넣을 때는 `images/` 폴더에 넣고 `index.html`에서 `img src="images/파일명"`으로 연결하면 됩니다.
